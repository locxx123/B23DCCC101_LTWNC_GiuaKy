# Mini Library

Ứng dụng tra cứu và mượn/trả sách cho thư viện khoa.

## Chạy dự án

```bash
npm install
npm run dev
npm test
```

Thêm `?fail` vào URL (ví dụ `http://localhost:5173/?fail`) để giả lập API lỗi.

## Công nghệ

React + TypeScript (Vite), Redux Toolkit, Zustand, React Router, Jest + React Testing Library.
